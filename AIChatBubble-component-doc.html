Reusable Component System

AIChatBubble

Unified styling untuk AI Co-Author dan AI Assistant dengan bubble prompt yang konsisten — satu komponen, dua interface.

Code Example

Kode ini digunakan oleh AI Co-Author di Docs Studio dan AI Assistant di Chat Studio.

// Import reusable component
import { AIChatBubble } from '@/shared/components/AIChatBubble';

// AI Co-Author - Edit & Undo
<AIChatBubble
  role="user"
  content="Buatkan dokumen laporan teknis"
  variant="coauthor"
  language="id"
  onEdit={handleEdit}
  onUndo={handleUndo}
/>

// AI Assistant - Copy & Feedback
<AIChatBubble
  role="assistant"
  content="Halo! Saya akan membantu..."
  assistantName="AI Assistant"
  assistantColor="var(--brand-primary)"
  isStreaming={true}
  language="id"
/>

Features

Unified Styling
Sama bubble styling, action bar, dan typography untuk AI Co-Author dan Assistant.
Reusable Code
Satu komponen digunakan oleh Docs Studio dan Chat Studio dengan prop variant.
Action Bar
Edit, Copy, Undo, Feedback buttons muncul on hover untuk clean interface.
Expandable Prompts
Prompt panjang bisa di-expand/collapse dengan satu klik untuk long content.
