One bubble. Both worlds.

AIChatBubble unifies the styling for AI Co-Author (document editing) and AI Assistant (general chat) — same prompt bubbles, same action bars, same theme awareness.

Component menangani: expandable prompt, reasoning display, edit/undo, streaming indicator, action bar.

Reusability

Komponen ini digunakan oleh AI Co-Author di Docs Studio (edit/undo, expandable prompts) dan AI Assistant di Chat Studio (general answering, reasoning timeline). Keduanya berbagi gaya bubble, header avatar, dan action toolbar — hanya berbeda pada prop variant.

// AI Co-Author (Docs Studio)
import { AIChatBubble } from '@/shared/components/AIChatBubble';

// User message — coauthor variant
<AIChatBubble
  role="user"
  content={msg.content}
  variant="coauthor"
  language="id"
  isReverted={msg.isReverted}
  onEdit={() => handleEdit(msg.id)}
  onUndo={() => handleUndo(msg.id)}
/>

// Assistant — standard variant
<AIChatBubble
  role="assistant"
  content={msg.content}
  reasoningContent={msg.thinking}
  assistantName="AI Assistant"
  assistantColor="var(--brand-primary)"
  isStreaming={isGenerating}
  language="id"
/>

Props

Variant

coauthor — edit/undo buttons, expandable prompt
assistant — copy/feedback buttons

Theme

CSS variables --bg-user-bubble, --brand-primary, --text-primary — otomatis adapt light/dark

Features

Expandable prompts, reasoning display, streaming dots, attachments, edit mode

Usage

AIChatBubble, UserPromptBubble, AssistantMessageBubble, CoAuthorMessageBubble

Unified Styling

Sama bubble radius, padding, dan shadow untuk user dan assistant. Tidak ada perbedaan visual yang tidak perlu.

Theme Aware

CSS variables untuk light dan dark mode. Tidak perlu dua versi komponen.

Reusable

Satu komponen digunakan oleh Docs Studio (Co-Author) dan Chat Studio (Assistant).

Expandable

Prompt panjang bisa di-expand dan di-collapse dengan satu klik.
